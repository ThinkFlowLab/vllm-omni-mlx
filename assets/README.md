# Logo assets

The project wordmark preserves the vLLM yellow/blue folded v, uses a spectrum-colored Omni O, and adds a teal MLX X.

- `vllm-omni-mlx-logo-light.svg`: transparent wordmark for light backgrounds
- `vllm-omni-mlx-logo-dark.svg`: transparent wordmark for dark backgrounds

Use the SVGs at their original aspect ratio with clear space around them. The main README displays the appropriate variant at 620 px wide. Lettering is outlined; no fonts, scripts, or external resources are required.

## Source credits

The vLLM geometry comes from the [official vLLM media kit](https://github.com/vllm-project/media-kit), specifically [vLLM-Full-Logo.svg](https://github.com/vllm-project/media-kit/blob/main/vLLM-Full-Logo.svg). Its proportions are preserved, with tightly cropped outer bounds and light lettering for the dark-background variant. Official colors are yellow `#FDB515` and blue `#30A2FF`.

The spectrum-colored O is a newly outlined interpretation of the [vLLM-Omni identity](https://github.com/vllm-project/vllm-omni/blob/main/docs/source/logos/vllm-omni-logo.png), rather than a copy of that raster asset. The teal MLX extension and layout were prepared for this project. No Apple or third-party MLX logo is included.

New lettering is outlined from [Liberation Sans and Liberation Mono](https://github.com/liberationfonts), licensed under SIL Open Font License 1.1. The distribution notice is retained in [FONT-NOTICE.txt](FONT-NOTICE.txt); no font software is embedded.
